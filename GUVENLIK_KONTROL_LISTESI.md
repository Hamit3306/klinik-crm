# Güvenlik ve Üretim Kontrol Listesi

- [ ] Varsayılan `admin / klinik2026` hesabı değiştirildi.
- [ ] `.env` dosyası Git ve herkese açık klasörlerin dışında tutuluyor.
- [ ] Uygulama yalnızca HTTPS üzerinden açılıyor.
- [ ] `META_APP_SECRET` tanımlı ve webhook imzası doğrulanıyor.
- [ ] Meta erişim tokenları düzenli yenileniyor veya sistem kullanıcısıyla yönetiliyor.
- [ ] Sunucu güvenlik duvarında yalnızca gerekli portlar açık.
- [ ] Günlük şifreli veritabanı yedeği alınıyor.
- [ ] Personel erişimleri görev bazında sınırlandırılıyor.
- [ ] İşten ayrılan personelin erişimi aynı gün kapatılıyor.
- [ ] KVKK aydınlatma ve açık rıza metinleri güncel.
- [ ] Saklama ve silme süreleri yazılı politika olarak tanımlı.
- [ ] Üretim loglarında şifre, token ve tam mesaj içerikleri tutulmuyor.
